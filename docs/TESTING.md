## 4. 1×/2×/3× 画质

使用同一截图范围记录基础尺寸，例如：

```text
1× = 1823 × 782
2× = 3646 × 1564
3× = 5469 × 2346
```

检查：

- [ ] 2× 宽高严格为 1× 的 2 倍
- [ ] 3× 宽高严格为 1× 的 3 倍
- [ ] 宽高比不变
- [ ] 2×/3× 不是由 1× 插值放大
- [ ] 放大查看 Dimension 数字，3× 拥有更多真实细节
- [ ] Arc/Spline 边缘比普通系统截图更细腻

## 13. 1.0.1 命令回调异常修复（2026-09-12）

实测点击“框选区域”出现 `Unhandled e0434352h Exception`。现有日志不足以确定最初触发异常的 API；已确认并修复截图异常逃出 AutoCAD 命令回调的处理缺口。

- CommandContextRunner 在回调内部捕获异常，始终返回成功完成的 Task；等待 AutoCAD 返回后，再通过 ExceptionDispatchInfo 将原异常交给调用方处理。
- 异步按钮拦截同步/异步异常与错误提示处理器自身的异常，并恢复可执行状态。
- 窗口恢复使用 WPF Dispatcher，已关闭的窗口不再重新 Show。
- 失败日志写入 `%LOCALAPPDATA%\CadHdScreenshot\Logs`，包含阶段、完整堆栈、插件路径和模块标识；日志写入失败不能再次抛异常。
- 浮动窗口初始状态显示 1.0.1，便于确认更新是否实际加载。

自动化回归：53 项测试全部通过，包含 11 项本轮新增测试；异常处理测试先复现失败再通过。测试通过源文件链接覆盖实际的 CommandContextRunner/AsyncRelayCommand，不引用 Autodesk DLL。完整 AutoCAD 2024 Release 构建通过。

## 14. 1.0.2 离屏渲染修复（2026-09-12）

1.0.1 的实际日志已给出失败点：`Manager.AcquireGraphicsKernel` 在构建 GraphicsKernel 包装对象时抛出 InvalidOperationException。独立 AutoCAD 2024 进程加载生成的 DXF 后，使用原代码复现相同堆栈。

修复两处接口使用错误：离屏渲染申请 Drawing3D 内核；在复制当前视图参数后，将 ViewportExtents 设为归一化范围 (0,0)-(1,1)。仅修改内核时，测试生成全白图；补上视口修复后，800×480、1600×960、2400×1440 均包含正确的线条、圆和文字，非白像素分别为 2980、6026、9063。

完整 Release 构建 0 警告、0 错误，53 项 NUnit 测试全部通过。原生渲染回归代码与测试 DXF 保存在 tests/CadHdScreenshot.AutoCAD.SmokeTests，不加入普通 NUnit 测试入口，运行方式见其 README。

本轮没有验证业务图纸、RasterImage、尺寸标注或整个浮动窗口交互。当前运行进程需要在更新 bundle 后重启，不能用已加载的 1.0.1 判断修复效果。日志记录的现有安装目录为 C:\Program Files (x86)\Autodesk\ApplicationPlugins\CadHdScreenshot.bundle，请核对实际加载路径并替换该目录，避免多处安装导致旧版本继续加载。
