# AutoCAD 2024 实机测试清单

本项目的核心价值必须通过 Windows + AutoCAD 2024 实机验证。纯单元测试不能替代下面的检查。

## 1. 基础环境

- [ ] AutoCAD 2024 x64 正常启动
- [ ] 插件 bundle 被自动加载
- [ ] Ribbon 出现“高清截图”按钮
- [ ] 点击后只创建一个浮动窗口
- [ ] 浮动窗口可自由拖动、缩放、跨显示器
- [ ] 窗口打开时 CAD 仍可缩放、平移、编辑

## 2. 框选截图

- [ ] 点击“框选区域”后窗口隐藏
- [ ] CAD 获得输入焦点
- [ ] 第一/第二点可正常指定
- [ ] Esc 能取消且窗口恢复
- [ ] 截图后 CAD 视图不发生永久变化

## 3. 选择对象截图

- [ ] 支持标准选择方式
- [ ] Enter 确认
- [ ] 自动计算整体 Extents
- [ ] 安全边距正确
- [ ] Esc 取消无副作用

## 4. 1×/2×/3× 画质

使用同一截图范围记录基础尺寸，例如：

```text
1× = 1823 × 782
2× = 3646 × 1564
3× = 5469 × 2346
```

检查：

- [ ] 2× 宽高严格为 1× 的 2 倍
- [ ] 3× 宽高严格为 1× 的 3 倍
- [ ] 宽高比不变
- [ ] 2×/3× 不是由 1× 插值放大
- [ ] 放大查看 Dimension 数字，3× 拥有更多真实细节
- [ ] Arc/Spline 边缘比普通系统截图更细腻

## 5. 最高优先级业务场景

准备一张包含以下内容的测试 DWG：

```text
客户 JPG/PNG 户型 RasterImage
+
沙发 CAD Block
+
Dimension
+
MText/Text
+
Leader
+
Polyline/Arc/Spline
```

分别导出 1×、2×、3×。

必须满足：

- [ ] RasterImage 正常显示
- [ ] RasterImage 不偏移
- [ ] RasterImage 比例不改变
- [ ] RasterImage 与 CAD 沙发位置关系一致
- [ ] 沙发模型不变形
- [ ] Dimension 文字和箭头清晰
- [ ] 中文文字可读
- [ ] 图层显示状态与当前 CAD 一致

## 6. 颜色模式

- [ ] 原色图
- [ ] 黑白图
- [ ] 白底图
- [ ] 黑白灰图
- [ ] 突出色 A
- [ ] 突出色 B
- [ ] 黑白灰保留 ACI 8、9、250、251、252、253、254
- [ ] 白色转透明自动强制 PNG

## 7. 文件输出

- [ ] PNG 可正常打开
- [ ] JPG 可正常打开
- [ ] 自动保存命名不覆盖已有文件
- [ ] 每次另存为可正常选择位置
- [ ] 编码失败不留下损坏的最终文件

## 8. 剪贴板

- [ ] 开启时可直接粘贴到微信/千牛/PS
- [ ] 关闭时不修改剪贴板
- [ ] 剪贴板被占用时会重试/给出非阻塞提示
- [ ] 剪贴板失败不影响已成功保存的图片

## 9. 高像素安全

- [ ] 普通 2×/3× 不弹风险提示
- [ ] >1.5 亿像素显示高风险提示
- [ ] >3 亿像素显示极限提示
- [ ] >5 亿像素禁止执行
- [ ] 超大宽高比给出提示但不擅自改变截图范围

## 10. 异常恢复

故意触发或模拟：

- [ ] 用户 Esc
- [ ] 保存目录不可写
- [ ] 文件被占用
- [ ] 剪贴板被占用
- [ ] 图片编码异常
- [ ] 渲染异常

每种情况下确认：

- [ ] DWG 图元未改变
- [ ] 图层未改变
- [ ] RasterImage 未移动
- [ ] 当前视图恢复
- [ ] 浮动窗口可继续使用

## 11. 性能基线

针对常规家具户型图记录：

```text
2×：目标 1-2 秒级或接近该范围
3×：目标数秒内
```

实际性能取决于 DWG、RasterImage 分辨率、CPU/GPU 和 AutoCAD 图形系统，因此记录真实机器结果而不是硬编码绝对时间断言。
