# CAD 综合工具 1.4.2

1.4.2 修复含多层嵌套块时整块被跳过的问题：逐层校正普通块内的尺寸标注、单行文字和多行文字；无文字的动态人物块保留动态定义及参数，不再阻止外层标注校正。复制内容使用深度克隆，保留嵌套对象的附属数据；校正文字时尽量保持显示中心位置。仍以二维俯视图为适用范围。

已编译通过；2026-09-22 已读取用户当前沙发块确认嵌套结构。用户选择自行测试，本版尚未完成 CAD 内显示验收。集成回归程序已补充递归文字方向、嵌套图形几何和动态参数检查；不能将编译成功或输入法单元测试等同于镜像效果验证。

输入法功能继续按鼠标进入 CAD 主窗口触发英文，不依赖 UIA 对普通命令框的识别。文字编辑必须有明确的编辑命令、编辑控件和原生编辑器，残留对象不会触发中文。手动切换优先仅在本次鼠标停留内有效，移出再进入会重新应用英文。CAD 在后台时不会影响前台其他软件。

适用 AutoCAD 2024 / Windows x64 / .NET Framework 4.8。

保留截图、直接复制到剪贴板、自定义命令、批量标注样式和输入法切换功能。输入法开关立即生效、按 Windows 用户保存，关闭浮动面板不会关闭已启用的服务。

## 镜像块文字校正

1. 先按正常方式镜像块。
2. 打开“块工具”，点击“选择镜像块并校正文字”，选择文字反向的块后按 Enter；也可直接输入 `CADFIXMIRRORTEXT`。
3. 工具会逐层检查镜像变换以及块内尺寸标注、普通文字的实际方向；已无镜像缩放但标注仍倒置的块也可以修复。一次 `UNDO` 可撤销本次修改。

校正后的块是该实例专用的匿名静态块，不再跟随原命名块定义更新。仅对含文字的普通嵌套块生成独立定义；不含文字的动态子块完整保留。直接选择动态块、属性块，或需要修改文字的子块本身是动态块、属性块、外部参照等不支持的结构时，会跳过整个选择实例并提示。

## 输入法使用

1. 用原自定义命令（默认 `QQ`）打开工具，或输入 `CADIMESET` 直接打开输入法标签。
2. 先在 Windows 中选择微信输入法、搜狗或微软拼音，再勾选“启用 CAD 智能输入法切换”。首次安装默认关闭。
3. CAD 在前台时，鼠标移入 CAD 主窗口先切英文；真正进入已确认的文字编辑器、标准文件对话框的文件名框时切中文。
4. 同一个输入场景中，手动切换优先。插件不持续强制某一模式；切换失败也不会不断重试。
5. CAD 在后台、工具面板、地址路径和未确认的输入框保持原状。关闭开关会移除焦点监听、停止定时检测并释放输入法接口。

支持 `CADIMEON`、`CADIMEOFF`、`CADIMESTATUS`、`CADIMESET`、`CADIMEDIAG`、`CADIMERELOAD`。诊断开关也可在面板操作。日志只记录场景、接口和模式，不读取输入内容、图纸名称或文件路径。

设置位于 `%APPDATA%\CadHdScreenshot\ime-settings.xml`；诊断日志位于 `%LOCALAPPDATA%\CadHdScreenshot\Logs\ime.log`，5 MB 轮转、保留 3 份。

## 实现及兼容边界

- TSF 线程级 compartment 查询/设置当前中文输入法模式；不可查询时尝试 IMM32。不会自动安装、激活或替换输入法，也不模拟 Shift / Ctrl+Space。
- 已识别的中文键盘布局才允许切换。查询不可靠时保持不变；英文键盘布局不强制切换到某个中文输入法。
- AutoCAD 字符串提示事件和 InplaceTextEditor 状态判断实际文字编辑阶段；不会仅凭 MTEXT/TEXT 命令启动就切中文。
- 进程内焦点事件监听、100 ms 鼠标/焦点检查、后台单任务 UIA 查询；切换前再次校验焦点和鼠标。普通 CAD 鼠标进入路径不等待 UIA。禁止全局键盘钩子。
- 属性编辑器、第三方控件、部分表格/动态输入控件若无法确认用途会保持原状。微信/搜狗的不同版本、TSF 状态同步、特定文件对话框仍需实机兼容测试。本版不宣称覆盖设计文档全部 T01–T28 场景。
- 输入法测试覆盖场景分类、手动优先、去抖、失败退避、开关重置和配置持久化；不能代替 CAD 内原生接口与 IME 厂商测试。

## 构建与安装

运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，如 AutoCAD 路径不同，增加 `-AutoCAD2024Dir '实际路径'`。需要 .NET SDK 和 NuGet 中的 .NET Framework 4.8 引用程序集；可通过 `-PackageSource`、`-PackagesDirectory` 使用离线包。

构建、测试完成后生成 `artifacts\CadHdScreenshot.bundle` 和 ZIP。退出 CAD 后运行 `install.ps1`，自动备份并更新已存在的插件安装目录，不需要手工解压。两个目录都有旧插件时保持版本一致。系统级目录可能需要管理员权限。脚本不修改 CAD 安全设置。
