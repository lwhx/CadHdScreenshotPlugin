# AutoCAD 标注方向回归

这是需要在 AutoCAD 2024 进程内运行的集成测试，不属于 `CadHdScreenshot.Tests` 的输入法测试。

1. 使用 `dotnet build -c Release` 构建本项目。
2. 在测试图中放置普通块：至少包含两条尺寸标注，可包含曾被 1.4.0 处理后仍倒置的块。
3. 在 CAD 中用 `NETLOAD` 加载生成的 `CadHdScreenshot.MirrorRegression.dll`。
4. 运行 `CADMIRRORGREEN`。结果写入 DLL 同目录的 `regression.log`。

测试直接编译生产服务源文件。它会复制当前空间的块，在最外层始终回滚的事务中调用生产校正流程；不会提交测试副本。另创建横向/纵向镜像、旋转 30° 的样例，检查尺寸标注实际生成的 MText 阅读方向、图形和尺寸端点、原实例身份、同名块引用以及重复运行的幂等性。

本测试的阅读方向断言以世界坐标俯视图为基准，针对普通二维平面标注。不要据此声称任意三维视角或嵌套属性块已验证。

1.4.2 增加递归检查嵌套尺寸、DBText/MText 的镜像和阅读方向，比较嵌套曲线采样点、动态块定义及参数。合成样例同时覆盖直接文字和外层无镜像但内层有镜像的块。当前版本回归程序已编译，尚未运行完成，实际显示仍待 CAD 验收。
